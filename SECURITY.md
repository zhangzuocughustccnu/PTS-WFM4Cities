# Security policy

## Supported version

Security fixes are provided for the latest major release.

| Version | Supported |
|---|---|
| 3.x | Yes |
| 2.x | No |

## Reporting

Do not publish a security-sensitive report as a public issue. Contact the
maintainers using the address in AUTHORS.md with:

- the affected version;
- a minimal reproduction;
- the potential impact;
- any suggested mitigation.

WFM4Cities performs local numerical analysis and contains no telemetry,
authentication, remote execution, or automatic file upload. Users should still
review untrusted input files and dependency updates in their own environment.
